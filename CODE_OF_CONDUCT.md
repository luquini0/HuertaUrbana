# Código de convivencia

Plantbook es un espacio abierto para aprender a cultivar. Para que sea acogedor para todas las personas:

- Tratá a los demás con respeto y paciencia; todos empezamos sin saber.
- Criticá ideas y datos, no personas. Las correcciones son bienvenidas y se hacen con amabilidad.
- Citá fuentes cuando afirmes algo importante (INTA, universidades, publicaciones técnicas).
- No se toleran el acoso, la discriminación ni el spam.

Quienes mantienen el proyecto pueden editar, rechazar o eliminar aportes que no cumplan estas pautas.
